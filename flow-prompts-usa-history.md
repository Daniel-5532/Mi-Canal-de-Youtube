# Google Flow prompts (STICKMAN style): The ENTIRE History of the United States in 10 Minutes

Image prompts for a stickman explainer video. Each prompt is self-contained and ends with the same style tail so every image matches.
Scene names and timestamps match `script-history-of-usa-10-minutes.md`.

**STYLE TAIL used in every prompt (copy it if you write your own):**
`Minimalist 2D stickman explainer style, simple black stick figures with round heads and thin limbs, hand-drawn doodle outlines, flat colors with a few bright accent colors, clean plain off-white background, 16:9, no text, no letters.`

**How to use**
1. Generate each image in Flow (or in its image tool).
2. If you want motion, use image-to-video with this animation prompt: `Gentle 2D animation, the stick figures bob and move slightly, slow camera push-in, keep the same flat doodle style.`
3. Add names, dates, and titles in your video editor. AI image tools garble text, so every prompt asks for none.
4. Use colored clothes or props (hats, flags, crowns) to tell groups apart; no real people are depicted, so there are no likeness problems.

## Tips
- **Same style, every time:** always keep the style tail identical. If one image looks different, add `same style as the previous images` and regenerate.
- **Character consistency:** if Flow lets you use a reference image, upload your first stickman and reuse it so the character looks the same in every scene.
- **Rest the viewer's eye:** change the camera in the editor (zoom in, pan, flash a name or date) every 3-5 seconds, since stickman videos rely on motion graphics and text.
- **Label AI content:** mark the video as containing AI-generated or altered content when you upload to YouTube.
